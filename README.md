# The Living Gallery — iPhone Edition

An interactive, AR-style gallery prototype. This is a simulated experience, not camera-tracked augmented reality.

## Run locally

Open `index.html` in a desktop browser, or run `python -m http.server 8000` in this folder and visit http://localhost:8000.

## Publish to GitHub Pages

1. Create a public repository named `living-gallery` on GitHub.
2. Upload `index.html` and `README.md` to the repository root, or push the folder using Git.
3. Under Settings → Pages, choose Deploy from a branch, `main`, `/ (root)`, and Save.
4. Open `https://YOUR-USERNAME.github.io/living-gallery/` in Safari on the iPhone.

The image is embedded inside the HTML; no extra asset files are needed.

## Notes

Phone motion features may require user permission. Safari can restrict motion features depending on settings and browsing context.
